# Projects

## 01 - Project 1 - Radio

Assembled and tested an AM/FM/PM radio system that connected communication theory to a complete receiver implementation. The project included PCB soldering and staged verification of the radio sections, antenna operation, RF amplification, filtering, mixing and heterodyning, local-oscillator operation, a fixed 455 kHz intermediate frequency, detection, and practical signal troubleshooting. The work also examined why filtering is performed before amplification, how mixers translate RF signals to a common IF, and how AM, FM, and PM encode information on a carrier.

AM demonstration: https://youtu.be/HXfNcfTJlf4

## 02 - Project 2 - Phase-Locked Loop

Built and tested a phase-locked-loop frequency-synthesizer circuit using a phase/frequency detector, loop filter, voltage-controlled oscillator, and divider feedback architecture. The implementation used a Fox F1144H TTL clock oscillator as the stable reference source in place of the discrete crystal-oscillator section. The project reinforced closed-loop phase and frequency locking, VCO control, frequency synthesis, oscilloscope verification, and the role of PLLs in clock generation and signal demodulation.
